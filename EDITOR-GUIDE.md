# Editing Hong Yang’s website

Open <https://hong-portfolio-htq7wor5.sanity.studio/edit> and sign in with your
approved owner account. Bookmark this address for future editing.
Only the two approved owner accounts can enter; public visitors cannot edit. The five buttons on the left match the website:
**Home, Paintings, CV, Artist Statement, About**. On a phone, use the top row of tabs.

All five pages open in **Edit on page** mode. Click the actual images and text to
change them. Use **Mobile** to check the narrow layout, or **Use forms** for extra
controls. The draft preview is not public.

- **Save draft** keeps your work for later without updating the public website.
- **Publish** asks for confirmation, then updates the selected page.
- Refresh the public website to see published changes.
- Leaving with unsaved edits prompts you to save or discard them.

## Home

Click the homepage image to replace it, and click its caption or the Paintings
button label to change the text. Image descriptions are filled automatically;
there is no manual description or homepage-body-text field. Existing stored text
is preserved. Uploading an image alone does not publish the page.

## Paintings

Paintings opens in **Edit on page** mode: the canvas is the actual website,
with editing enabled only inside the signed-in editor.

- Click a collection name, artwork title, year, medium, or dimensions to edit in place.
- Press Enter or click elsewhere to finish. Esc cancels the current text edit.
- Click an artwork image to choose a replacement image.
- Click **Add artwork** beneath a collection to upload one or several works.
- Under each artwork, use **Move up** / **Move down**, or drag its **↕ Drag** handle
  onto another artwork in the same collection.
- **Remove artwork** asks for confirmation and removes that placement from the
  draft. Save/Publish to keep the change; the artwork and original image remain
  stored and can be restored through **Use forms → Use existing artwork**.
- Use the toolbar **Add collection** button to add a new category.
- **Save draft** and **Publish** collect any still-focused text before saving.
- Artwork controls keep pending text edits when clicked or dragged. A status line
  confirms the operation. If the editor is out of date or does not respond, it
  displays a reload instruction. Removal uses an in-editor confirmation dialog.

Choose **Use forms** for collection/works ordering, descriptions, detail images,
and fields not shown on the webpage. Choose **Edit on page** to return to the canvas.
The controls below describe the additional form mode.

### Collections

Click **Add collection** to create a category, or **Add existing collection** to
restore a saved one. Edit its title and optional introduction. Enable **Show
introduction on website** if you want the text visible.

Drag the handle or use the up/down arrows to arrange the collections. Removing a
collection from Paintings hides it from the selected order; it does not erase its
stored artworks. You can add the collection back later.

### Artworks

Inside a collection:

- **Upload artworks** accepts one or several image files and creates a card for each.
- **Add artwork** starts a blank card. Upload its main image before publishing.
- **Use existing artwork** adds a work already stored in the project.
- **Dimensions (inches by default)** is always visible on each artwork card.
- **Edit details** opens the title, year, medium and description.
- **Add detail images** uploads extra views. Remove an extra view with its Remove button.
- Drag handles or use up/down arrows to change the artwork order.

Missing artwork medium defaults to **Oil on canvas**. Existing media such as
**Oil on panel** are preserved. Click the medium beneath any artwork to edit it;
saving/publishing Paintings stores the displayed defaults for visible works.

Dimensions default to inches. Enter `24 × 36`, or explicitly include another unit,
such as `60 × 80 cm`. Image descriptions and URL slugs are generated automatically;
no manual technical fields are required.

**Remove from collection** removes only that placement. The artwork document and
its images remain stored. Editing an artwork used in several collections changes
that work everywhere.

### Publishing Paintings

**Publish Paintings** publishes the visible collection order, those collections,
and their artwork drafts together. It does not publish unrelated Home, CV,
Artist Statement or About changes. Draft works outside the visible collections
stay drafts. Revision conflicts cancel the entire publication rather than leaving
a partially published collection.

Click **Whole portfolio** to leave an individual artwork preview and see the full
selected portfolio. A focused preview may show an item before it is publicly visible.

## CV

CV opens with a rich-text box, like Artist Statement. Type or paste the whole CV,
then format paragraphs, headings, bold or italic text. Existing structured entries
are prefilled as text until you first edit it. The original entries remain stored
under **Previous structured entries**. Once text is saved/published, that text is
used instead of the old entry layout. Publishing empty text clears the displayed CV.
**Edit on page** also supports editing the saved CV text directly.

## Artist Statement

Type directly in the text area. Enter creates a new paragraph. Select words and
click **Bold** or **Italic**. Click within a paragraph and choose **Heading** or
**Paragraph** to change its style. Pasted content is treated as plain text.
An empty published statement clears the previous statement.

## About

Click the biography to edit it directly. The artist name is not repeated in the
About body; it remains editable through **Use forms**. Enter adds a biography
line; Ctrl/Cmd+Enter finishes editing. Click the portrait to replace it, or use the
upload button if no portrait exists. **Use forms** also supports portrait removal. The name also appears in the public website navigation and
copyright. CV and Artist Statement are edited independently.

## Image uploads

Use JPG, PNG, WebP or GIF, up to 20 MB per file. Images are uploaded when selected;
they do not appear on the public page until its content is published.

## Existing content and conflicts

Earlier CV, statement and collection ordering are copied into the editor when the
new corresponding page document does not yet exist. Existing document IDs and
unrelated fields are preserved. No cloud documents are deleted during setup.

If another member changes the same content, the editor retains your inputs and
shows an error instead of overwriting their version. Use **Reload saved version**
to review the saved content before retrying. Explicitly empty published pages
clear their earlier content rather than restoring the legacy fallback.

The editor uses your own project account. A deployment token cannot replace
member upload/edit permissions. Never share passwords or paste tokens into the editor.

Advanced document tools remain available through **Advanced tools** if needed.
